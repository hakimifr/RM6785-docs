title: realme UI 2.0 Update not Showing Up
---

If you're stuck on Android 10 (Realme UI 1) and can't
get Android 11 (Realme UI 2) upgrade:

1. dial `*#3954391#`
   (Toast Message will pop up saying  'switch activated')

1. dial `*#391#`.
   **choose your region and reboot.**

You should be able to get the update now.
